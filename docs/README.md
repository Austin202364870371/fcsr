# Research Questions

FCSR is organized around research questions. A document records the hypothesis, current assets, evaluation boundary, and next experiment; it is not a substitute for reporting evidence from a completed run.

| Question | Scope | Status |
|---|---|---|
| [RQ1: Skill Retrieval](rq1-skill-retrieval.md) | Contract-guided single-skill and multi-skill retrieval. | Implemented pipeline and initial Hard-pool comparison. |
| [RQ3: Agent Planning](rq3-agent-planning.md) | Planning and replanning over retrieved Skills. | Research design. |
| [RQ4: Agent Reflection](rq4-agent-reflection.md) | Reflection and experience reuse after execution. | Research design. |
| [RQ5: Agent Evaluation](rq5-agent-evaluation.md) | End-to-end Agent evaluation and reporting. | Research design. |

Skill organization is not an active repository workflow. The current codebase focuses on retrieval and keeps later Agent questions as research specifications rather than partial runtime pipelines.
